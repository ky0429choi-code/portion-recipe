# 계정 관리

계정은 운영 DB의 `USERS` 탭에서 관리하고, 비밀번호 관련 작업은 **GAS 편집기의 관리자 함수**로만 합니다.
비밀번호 원문은 시트 어디에도 저장되지 않습니다.

## USERS 탭 열

| 열 | 값 | 설명 |
|---|---|---|
| `userId` | 소문자 아이디 | 로그인 아이디 (대소문자 구분 없음) |
| `displayName` | 이름 | 화면 오른쪽 위에 표시 |
| `role` | `ADMIN` / `USER` | 현재 기능은 동일, 확장 기능에서 구분 |
| `siteScope` | `*` 또는 `SITE-A,SITE-B` | 볼 수 있는 인당량 사업장. 비우면 아무것도 안 보임 |
| `status` | `PENDING` / `ACTIVE` / `DISABLED` | |
| `passwordHash` 이하 | 자동 관리 | **직접 수정하지 않음** |

> 현재 운영 DB 인당량은 `siteId = REGION_UNASSIGNED`(사업장 미지정)입니다. 이 자료를 보려면 `siteScope`에 `*` 또는 `REGION_UNASSIGNED`가 있어야 합니다.

## 새 계정 발급

1. `USERS`에 행 추가: `userId`, `displayName`, `role`, `siteScope`, `status = PENDING`
2. GAS 편집기에서 `issueTempPasswords` 실행
3. 실행 로그의 임시 비밀번호를 본인에게 **직접** 전달 (메신저 단체방·이메일 본문 공유 지양)
4. 사용자가 72시간 안에 로그인해 새 비밀번호(4자 이상, 숫자만도 가능, 공백·아이디 포함 불가)로 변경
   - 짧은 비밀번호는 5회 실패 잠금으로 보호되지만, 시트(해시값)가 유출되면 쉽게 풀릴 수 있으므로 운영 DB 공유 범위를 최소로 유지

## 비밀번호 분실·재설정

`status`를 `PENDING`으로 바꾸고 `issueTempPasswords` 실행 → 기존 로그인은 모두 끊기고 새 임시 비밀번호 발급

## 잠금 해제

5회 실패 시 15분 자동 잠금. 즉시 풀려면 `lockedUntil` 칸을 비웁니다.

## 정지

`status`를 `DISABLED`로 바꾸면 다음 요청부터 바로 차단됩니다(로그인 중이어도).

## 의심 상황

`revokeAllSessions` 실행 → 전체 로그아웃. `AUDIT_LOG`에서 `LOGIN_FAIL`, `LOGIN_LOCK` 기록을 확인합니다.
