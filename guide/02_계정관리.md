# 계정 관리

평소에는 **앱의 [⚙ 계정 관리] 탭**(관리자만 보임)에서 모두 처리합니다. 시트나 편집기를 열 필요가 없습니다.
비밀번호는 시트에 해시로만 저장되며, 모든 변경은 `AUDIT_LOG` 탭에 남습니다.

## 앱에서 하는 일 (관리자)

| 하고 싶은 일 | 방법 |
|---|---|
| 새 사람 추가 | [계정 관리] → **＋ 새 계정 만들기** → 아이디·이름·권한·범위·**초기 비밀번호** 입력 → 계정 만들기 → 아이디와 초기 비밀번호를 본인에게 직접 전달 |
| 비밀번호 잊음 | 계정 선택 → **비밀번호 지정**에 새 비밀번호 입력 → 본인에게 전달 (그 사람의 다른 로그인은 끊김) |
| 이름·권한·범위 변경 | 계정 선택 → 기본 정보 수정 → 저장 |
| 퇴사·중지 | 계정 선택 → **계정 정지** (로그인 중이어도 바로 차단) / 다시 쓰려면 **사용 재개** |
| 5회 실패로 잠김 | 계정 선택 → **잠금 해제** |

- **"첫 로그인 때 본인이 비밀번호를 바꾸도록 요구"**를 켜 두면(기본값), 관리자가 정한 비밀번호는 첫 로그인 후 본인 비밀번호로 바뀝니다. 72시간 안에 첫 로그인을 해야 합니다.
- 비밀번호 규칙: 4자 이상(숫자만 가능), 공백·아이디 포함 불가
- 아이디 규칙: 영문 소문자·숫자·`.` `_` `-`, 3자 이상
- 사업장 범위: `*` = 전체. 현재 운영 데이터는 사업장 미지정(`REGION_UNASSIGNED`)이라 `*`를 권장
- 안전장치: 자기 계정 정지 불가, 마지막 관리자의 권한 해제·정지 불가

## 새 사람 등록 — 순서 요약

1. 관리자: 앱 → **⚙ 계정 관리 → ＋ 새 계정 만들기**
   - 아이디(예: `hong.gildong`), 이름, 권한 **사용자**, 범위 `*`, 초기 비밀번호(예: 4자리), "첫 로그인 때 변경 요구" ✔
2. 관리자: 아래 안내 문구를 **본인에게 직접**(1:1 메시지) 보내기 — 단체방에 올리지 않기
3. 사용자: 72시간 안에 로그인 → 본인 비밀번호로 변경 → 끝

## 모든 사용자

오른쪽 위 **[비밀번호 변경]** → 현재 비밀번호와 새 비밀번호 입력

## 비상: 관리자로 들어갈 수 없을 때

1. Apps Script 편집기에서 함수 **`recoverAdmin`** 선택 → ▷ 실행
2. 실행 로그의 `[관리자 복구] 아이디: … 임시 비밀번호: …` 확인
3. 그 아이디·임시 비밀번호로 로그인 → 새 비밀번호 설정

복구 대상: 스크립트 속성 `ADMIN_USER_ID`의 계정. 그 속성이 없거나 아이디가 없으면, 계정이 하나뿐일 때 그 계정.
계정이 여러 개인데 대상을 정할 수 없으면 아무것도 바꾸지 않고 로그로 안내합니다.

## 의심 상황

편집기에서 `revokeAllSessions` 실행 → 전체 로그아웃. `AUDIT_LOG`에서 `LOGIN_FAIL`, `LOGIN_LOCK` 기록 확인.

## 시트 직접 수정 (권장하지 않음)

`USERS` 탭의 `passwordHash`, `mustChange`, `passwordSetAt`, `failCount` 열은 직접 고치지 마세요. 아이디·이름·권한·범위·상태는 고칠 수 있지만 앱 화면을 쓰는 것이 안전합니다.
