# 모바일 설치 방법

앱 주소: **https://ky0429choi-code.github.io/portion-recipe/**

앱스토어 설치가 아니라 **웹앱(PWA)을 홈 화면에 추가**하는 방식입니다. 설치하면 아이콘(보라색 **PR**)이 생기고, 주소창 없이 앱처럼 전체 화면으로 열립니다.
업데이트는 자동입니다(다시 설치할 필요 없음).

## Android (갤럭시 등)

**Chrome**
1. Chrome으로 위 주소 열기
2. 로그인 화면 또는 상단의 **[📲 앱 설치]** 버튼 → **설치**
3. 버튼이 안 보이면: 오른쪽 위 **⋮ 메뉴 → "앱 설치"** 또는 **"홈 화면에 추가"**

**삼성 인터넷**
1. 삼성 인터넷으로 위 주소 열기
2. 하단 **≡ 메뉴 → "현재 페이지 추가" → "홈 화면"**
   (주소창 옆에 ⬇ 설치 아이콘이 보이면 그걸 눌러도 됩니다)

## iPhone

> **반드시 Safari**로 여세요. 카카오톡·네이버 앱 안에서 열린 화면에서는 설치가 안 됩니다. (오른쪽 아래 "Safari로 열기")

1. Safari로 위 주소 열기
2. 하단 가운데 **공유 버튼(□↑)** 누르기
3. 아래로 내려 **"홈 화면에 추가"** → 이름 "인당량" 확인 → **추가**

## 설치 후

- 홈 화면의 **인당량(PR)** 아이콘으로 실행 → 아이디·비밀번호 로그인
- 로그인 화면의 **[아이디 저장]**: 다음부터 아이디가 미리 채워짐 (비밀번호는 저장 안 함)
- 로그인 화면의 **[로그인 상태 유지 (8시간)]**: 체크하면 앱을 닫았다 열어도 8시간 동안 바로 메뉴 화면. 체크하지 않으면 앱을 완전히 닫을 때 로그아웃.
  - 개인 휴대폰에서만 쓰세요. 분실하면 관리자에게 알려 **계정 정지**(즉시 차단) 후 비밀번호를 다시 지정받으세요.
- 인터넷 연결이 필요합니다(오프라인 저장 없음 — 회사 자료를 휴대폰에 남기지 않기 위해).

## 예전 앱을 설치했던 경우

예전 "인당량 · 레시피" 아이콘도 같은 주소라 **그대로 새 화면이 열립니다.** 예전 화면이 보이면 앱을 완전히 닫았다가 다시 열거나, 아이콘을 지우고 위 방법으로 다시 추가하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 예전 화면이 계속 보임 | 앱 완전 종료 후 다시 실행 / 브라우저에서 주소를 열고 새로고침 |
| "서버에 연결할 수 없습니다" | 인터넷 연결 확인 (사내 와이파이에서 Google이 막혀 있으면 LTE로 시도) |
| 로그인이 3초 정도 걸림 | 정상 (비밀번호 보호 계산) |
| iPhone에 "홈 화면에 추가"가 없음 | Safari가 아닌 다른 앱 안에서 연 것 → Safari로 열기 |
